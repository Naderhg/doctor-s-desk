# Doctor's Desk

# موقع عيادة دكتور واحد — خطة البناء

موقع عربي (RTL) لعيادة طبيب واحد: المريض يحجز موعد ويتابع ملفه الطبي، والدكتور يدير جدوله وحجوزاته ويكتب الروشتات.

## 1. صفحات المريض

- الصفحة الرئيسية: تعريف بالدكتور، التخصص، الخدمات، مواعيد العمل، مكان العيادة، آراء المرضى، زر "احجز الآن".

- تسجيل حساب / دخول (بريد وكلمة مرور + Google).

- حجز موعد: اختيار نوع الكشف (كشف جديد / إعادة / استشارة فيديو)، تقويم بالأيام المتاحة، ثم المواعيد الفاضية فقط، ثم سبب الزيارة، ثم دفع العربون.

- مواعيدي: القادمة والسابقة، تأجيل أو إلغاء (حسب مهلة محددة)، رابط مكالمة الفيديو وقت الموعد.

- ملفي الطبي: البيانات الأساسية (السن، النوع، فصيلة الدم، الأمراض المزمنة، الحساسية، الأدوية الحالية)، رفع تحاليل وأشعة، تاريخ الزيارات.

- الروشتات: عرض وطباعة/تحميل PDF لكل روشتة كتبها الدكتور.

- الإشعارات داخل الموقع + تذكير برسالة SMS/واتساب قبل الموعد.

## 2. لوحة الدكتور

- نظرة عامة: مواعيد النهاردة، عدد الحجوزات، المتبقي، إحصائيات بسيطة (حجوزات الأسبوع، الإلغاءات، الإيرادات).

- التقويم: عرض يومي/أسبوعي لكل الحجوزات، تأكيد/رفض/تأجيل، تحديد الحضور أو الغياب.

- إدارة الجدول: أيام وساعات العمل، مدة الكشف، عدد المرضى في الساعة، الإجازات وأيام الغلق، فتح مواعيد استثنائية.

- قائمة المرضى: بحث، فتح الملف الطبي الكامل، تاريخ الزيارات والمرفقات.

- الزيارة: تسجيل الشكوى والتشخيص والملاحظات، كتابة روشتة (دواء + جرعة + مدة) مع قائمة أدوية محفوظة، طلب تحاليل/أشعة، تحديد موعد متابعة.

- إعدادات: سعر الكشف والعربون، محتوى الصفحة الرئيسية، الخدمات.

## 3. قواعد مهمة

- منع الحجز المزدوج على نفس الميعاد، ومنع الحجز في وقت مضى أو في إجازة.

- المريض يرى ملفه فقط؛ الدكتور يرى كل المرضى.

- تأكيد الحجز يتم بعد نجاح دفع العربون.

- سياسة إلغاء واضحة (مثلاً: إلغاء مجاني قبل ٢٤ ساعة).

## 4. ما يحتاج خدمات خارجية

- **الدفع (العربون):** يحتاج تفعيل بوابة دفع (Stripe/Paddle عبر Lovable أو مزود محلي بحساب الدكتور).

- **مكالمة الفيديو:** نستخدم رابط اجتماع لكل موعد عبر خدمة فيديو (Daily.co مثلاً) — يحتاج حساب.

- **SMS/واتساب:** يحتاج ربط Twilio أو ما شابه (اشتراك مدفوع ورقم معتمد للواتساب).

إلى أن تتوفر هذه الحسابات، نبني الحجز بحالة "بانتظار الدفع/الدفع في العيادة"، والإشعارات داخل الموقع فقط.

## 5. ترتيب التنفيذ المقترح

1. الواجهة العامة + تسجيل الدخول + قاعدة البيانات.

2. الجدول والحجز ومواعيدي ولوحة الدكتور.

3. الملف الطبي والروشتات والمرفقات.

4. الدفع، ثم الفيديو، ثم رسائل التذكير.
